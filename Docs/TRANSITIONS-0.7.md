# Historical 0.7 transition milestone

Version 0.7 introduced 29 independent Basic/Motion/Matte transition styles, a clip-boundary +, live two-source preview, duration/remove/apply-all and whole-timeline fit. The preview and export reused one renderer. Synthetic long-film testing on the host decoded a full export; a full long-film simulator export was stopped incomplete because software rendering was too slow.

This is historical scope, not the current release verification. Version 0.9 adds three initial local atmosphere styles and fixes fractional-overlap instruction coverage. See [current verification](VERIFICATION.md) and [coverage](FEATURE-COVERAGE.md). Neither version claims full VN cloud-effect equivalence.
